# peelbill

Peelbill is a Flutter app for splitting bills and expenses between friends. It helps groups calculate individual shares, track who paid, and settle up fairly.

## Features

- Add friends or participants for a shared expense
- Enter the total bill amount and who contributed
- Automatically calculate each persons share
- Support for uneven splits and custom adjustments
- Clear summary of balances owed and paid

## Getting Started

To run the app locally:

1. Install Flutter: https://docs.flutter.dev/get-started/install
2. Open the project in your IDE or terminal
3. Run:

```bash
flutter pub get
flutter run
```

## Project Structure

- `lib/main.dart`  app entry point
- `lib/`  application UI and logic
- `android/`, `ios/`, `web/`, `macos/`, `windows/`, `linux/`  platform-specific Flutter support

## Notes

This project is designed for friends who want to share expenses cleanly, whether dining out, traveling, or splitting utilities.
